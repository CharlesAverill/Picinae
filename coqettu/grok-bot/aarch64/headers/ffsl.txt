(* ffsl -- musl 1.2.6 (Alpine 1.2.6-r6), aarch64, compiled C

   SEMANTICS
   ---------
   musl's src/misc/ffsl.c:
       int ffsl(long i) { return i ? a_ctz_l(i)+1 : 0; }
   The binary: cbz x0 -> mov w0,#0; otherwise rbit x0,x0; clz x0,x0;
   add w0,w0,#1; then ret.  The rbit network is handled by reflection
   (lib/GrokBitRefl.v, brev_check); clz is lifted as 64 - N.size x (our
   LZCOUNT lifter fix, ../lifter/README_GROK.md).

   SPECIFICATION (man 3 ffs, Linux man-pages 6.9.1)
   ------------------------------------------------
     SYNOPSIS
            #include <strings.h>
            int ffsl(long i);

     DESCRIPTION
            The ffs() function returns the position of the first (least
            significant) bit set in the word i.  The least significant bit is
            position 1 and the most significant position is, for example, 32
            or 64.  The functions ffsll() and ffsl() do the same but take
            arguments of possibly different size.

     RETURN VALUE
            These functions return the position of the first bit set, or 0 if
            no bits are set in i.

   INPUT/OUTPUT SPECIFICATION (AAPCS64)
   ------------------------------------
   Input:   X0 = i (64-bit long); SP = sp; X30 = raddr; m = memory.
   Output:  At the RET (0x13b2bc): memory = m, SP = sp, X30 = raddr and
            ffsl_spec i (X0 mod 2^32), i.e. the int result W0 is
              - 0 if i = 0, or
              - b + 1 where b < 64 is the index of the lowest set bit of i.
            Callee-saved registers X19..X29, SP, Z8..Z15 and X30 are never
            written (ffsl_preserves_callee_saved, ffsl_preserves_x30).
