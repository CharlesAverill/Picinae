   ----------------------------------------------
     SYNOPSIS
            #include <wctype.h>
            int iswdigit(wint_t wc);
     DESCRIPTION
            The iswdigit() function is the wide-character equivalent of the
            isdigit(3) function.  It tests whether wc is a wide character
            representing a decimal digit.
     RETURN VALUE
            The iswdigit() function returns nonzero if wc is a wide character
            representing a decimal digit.  Otherwise, it returns zero.
   (musl classifies only the ASCII range here; wint_t is 32 bits.)
