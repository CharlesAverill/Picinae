This is an unmodified snapshot of the repository's committed shared lifter.
`SOURCE.json` records its commit and file hashes. Codex's bounded BSF32 adapter
is in the parent directory; no shared lifter files are modified by this work.

Pinning these files keeps lift reproduction independent of concurrent edits
to the shared tool. Updates should be reviewed and accompanied by regeneration,
provenance checks, type checks, and recompilation of the affected proofs.
